# 海马爸比本机桥接

从现有部署整理的第一方源码。`service.py` 提供本机登录、状态、摄像头事件、08:00至次日08:00睡眠日报和视频预览入口；`probe.py` 提供绑定及 XP2P 探测；`native-sdk/native_probe.py` 是 Linux Agora SDK 的独立探测脚本。源码归档与语法检查不代表所有取流路径均已实机验证；本次同步只读检查线上事件/睡眠能力，没有运行视频探测或重新登录。

## 部署

需要 Python 3.10+、OpenSSL；XP2P 探测还需要 Docker 和匹配架构的运行库。将本目录放在持久化磁盘中，在原主机继续保留其私有 `protocol.json`、`.session.json`、`.camera-identity.json` 等文件，权限设为600。新环境参考 `protocol.example.json` 填入自己合法取得的协议配置，不能直接使用占位符启动。运行 `python3 service.py`，服务只监听 `127.0.0.1:18874`。设置页 `/`、状态 `/status`；网页适配器见 `../feeding-web/baby_sleep.py`。

在新机器需要访问设置页时，可由用户自行建立 SSH 本地端口转发（如 `ssh -L 18874:127.0.0.1:18874 USER@HOST`），不要直接把登录/预览服务发布到公网。

`HAIMA_CAMERA_IP` 是可选的本地 ping 诊断目标；不配置则跳过 ping。`HAIMA_P2P_NAME` 是可选的精确设备选择条件，默认按型号/唯一候选选择。真实网络地址和设备名称只配置在本机。SDK 容器镜像固定摘要来自原部署，拉取可用性未在本次同步验证。

## 外部依赖与限制

本仓库不重新分发厂商/第三方的 `ct4.js`（登录验证脚本）、`agora-sdk.js`（浏览器视频 SDK）、`libiot_video_demo.so`、`xp2p-worker` 或 Linux SDK 压缩包。应自行通过原部署备份或合法 SDK 来源准备匹配版本；`xp2p-worker` 在部署上只有编译产物，其原始源码本次未找到，不能声称可以从本仓库重建该二进制。缺少这些依赖时，相关登录验证或视频探测功能不能完整运行。

已有有效会话与绑定时，读取事件/睡眠不依赖视频 SDK。不要将登录会话、协议密钥、视频令牌、设备绑定或家庭事件数据提交到 GitHub。
