# 维护计划

`main` 是喂养网页和 P50 Pro 接入的源码来源。部署配置与家庭数据保存在运行主机。

## 已有能力

- 独立局域网喂养网页，提供记录、修改、撤销、按天历史和 7 天／14 天统计。
- BOLOLO P50 Pro 云端状态查询与已保存会话续期。
- MQTT 上报解码与自动记奶。出水开始和带水量的结束上报配对后，记录默认奶量、原始水量和观察到的开始时间。
- 网页默认奶量跟随奶机设置，可改用家庭自定值。

## 后续验证

- 观察持续运行和重连后的自动记录。漏掉事件的时段通过手动补记处理。
- 取得原版 App 的有效历史接口参数后，再验证逐笔读取、时间含义和去重。
- 如需 Home Assistant，先用已验证的只读状态或网页摘要，按实际需要选择一种接入方式。
- 控制类能力需要单独的实机验证。设备的锁定和确认流程由设备本身处理。

测试和部署步骤见[网页说明](../feeding-web/README.md)，协议证据见[研究手册](PROTOCOL_RESEARCH.md)。
